# Power BI Data Professional Survey Dashboard

## 📊 Project Overview

An interactive **Power BI dashboard** developed to analyze and visualize survey data from data professionals. The project transforms survey responses into meaningful insights about career roles, salaries, programming language preferences, demographics, job satisfaction, work-life balance, and the difficulty of entering the data industry.

The dashboard demonstrates practical skills in **data analysis, data visualization, dashboard development, and communicating insights through interactive business intelligence reports**.

## 🎯 Project Objectives

* Analyze the distribution of data professionals across different job roles.
* Compare average salaries across different job titles.
* Identify the most popular programming languages among respondents.
* Explore the geographic distribution of survey participants.
* Analyze satisfaction with salary and work-life balance.
* Understand how difficult respondents found entering the data industry.
* Present key metrics through an intuitive and visually organized dashboard.

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* Data visualization and dashboard development
* Interactive charts and KPI cards
* Aggregations and analytical measures
* Data filtering and interactive visual exploration

## 📈 Dashboard Components

### Key Performance Indicators

* **Total Survey Takers**
* **Average Age of Survey Takers**

### Salary Analysis

A bar chart compares **average salary across different job titles**, allowing users to identify salary differences between data-related roles.

### Programming Language Analysis

A column chart analyzes respondents' **favorite programming languages** and their distribution across job roles.

### Geographic Analysis

A treemap visualizes the **countries represented by survey participants**, providing a high-level view of the survey's geographic distribution.

### Job Satisfaction

Gauge visuals analyze respondents' satisfaction with:

* **Salary**
* **Work-Life Balance**

### Career Entry Difficulty

A donut chart visualizes how respondents rated the **difficulty of breaking into the data industry**, ranging from very difficult to very easy.
